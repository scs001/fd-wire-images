# source-packs Specification

## Purpose
定义源包（主题化的指标目录切片）与订阅：服务端静态包定义按 filter 实时切目录
（目录即真相，不落库副本）、公开包列表/详情、登录订阅/退订、控制台「源包」页
——让个人用户以「主题包」为单位处理数百信息源，而非逐个指标。

## Requirements

### Requirement: 源包定义与公开浏览

源包为服务端静态配置（id/双语名/描述/filter），指标清单与计数按 filter 从指标
目录实时计算；包列表与包详情（含分页指标清单）为公开端点，免费档可用，不产生
计量入账。

#### Scenario: 包列表含计数
- **WHEN** 未登录访问 GET /api/v1/packs
- **THEN** 返回全部包与各自实时指标数

#### Scenario: 包详情切片
- **WHEN** 打开某包详情并翻页
- **THEN** 指标清单按该包 filter 从目录实时切出且分页稳定

### Requirement: 订阅与我的订阅

登录客户可订阅/退订源包（幂等，未知包 404，客户域隔离）；「我的订阅」返回
本人订阅包 id 列表；订阅态免费（不占行数额度）。

#### Scenario: 订阅幂等
- **WHEN** 同一客户重复订阅同一包
- **THEN** 幂等成功不产生重复行

#### Scenario: 我的订阅隔离
- **WHEN** 客户 A 查询订阅列表
- **THEN** 仅含 A 自己的订阅，不含任何 B 的数据

### Requirement: 控制台源包页

控制台左侧栏提供「源包」入口：包卡片墙（双语名/描述/指标数/订阅徽标）+
「仅看已订阅」过滤；包详情抽屉分页列指标并可跳转指标目录详情；订阅/退订即时
切换。

#### Scenario: 订阅即时可见
- **WHEN** 客户在包卡片点击订阅
- **THEN** 徽标即时切换且刷新后保持（我的订阅视图包含该包）
