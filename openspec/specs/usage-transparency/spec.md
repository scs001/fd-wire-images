# usage-transparency Specification

## Purpose
定义客户侧用量透明：登录客户可自助查询当月读取用量与档位额度余量，口径与计量入账、行数门、结算同源（metering_records 的 rows_returned），使「用完即停」对客户可见可预期。

## Requirements

### Requirement: 客户用量查询

登录客户可查询自己（且仅自己）的当月累计读取行数、档位含额、剩余额度；口径与内部用量查询、行数门判定同源一致。

#### Scenario: 自助查量
- **WHEN** 客户登录后打开控制台用量页
- **THEN** 看到当月已用行数、档位含额与余量，数字与内部后台对同一客户的用量查询一致

#### Scenario: 跨客户隔离
- **WHEN** 客户 A 构造请求试图查询客户 B 的用量
- **THEN** 请求被拒绝，不返回任何 B 的数据

### Requirement: 用量页正式化

控制台「用量」页由占位转正式：呈现余量、已用、当前档位与用完即停说明；「上线中」占位标记移除。

#### Scenario: 占位退位
- **WHEN** 打开控制台用量页
- **THEN** 展示真实用量数据，不再出现「上线中」占位

### Requirement: 额度耗尽可预期

额度余量低与耗尽时在控制台给出可见提示；耗尽语义与「余额不足」（可超额档）区分呈现，耗尽提示明示次月恢复与升档路径。

#### Scenario: 耗尽提示
- **WHEN** 客户当月额度用尽
- **THEN** 用量页明示额度耗尽、次月恢复，并给出升档引导
