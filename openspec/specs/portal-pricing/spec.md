# portal-pricing Specification

## Purpose
定义柏讯对外定价的四档模型与呈现口径：档位数字由后端数据驱动、公开端点活取、全部档位无超额单价（用完即停、次月恢复），自定义档经内部建档指派、不进公开列表。

## Requirements

### Requirement: 四档定价模型

公开定价为四档：免费（¥0/月，含 1,000 行/月）、基础（¥10/月，含 100,000 行/月）、标准（¥50/月，含 1,000,000 行/月）、自定义（询价）。免费/基础/标准面向公众公开；自定义档不进入公开档位列表。全部档位超额单价为零——不存在超额计费，到量即停。

#### Scenario: 公开端点返回新口径
- **WHEN** 定价改版上线后调用公开档位端点
- **THEN** 返回免费/基础/标准三档且月费与含额行数与上述裁决一致，旧三档与自定义档不在返回中

#### Scenario: 计费模型无超额
- **WHEN** 任一公开档位客户的当月读取行数超过其含额
- **THEN** 超出部分不产生任何超额计费（超额单价为零），由行数门拒绝

### Requirement: 用完即停、次月恢复

档位含额为自然月度额度。当月累计读取行数达到含额后调用被拒，次月自动恢复满额，无需人工干预。

#### Scenario: 到量即停
- **WHEN** 客户当月累计读取行数（rows_returned 口径）达到其档位含额
- **THEN** 后续经 wire 入口的调用被月度额度耗尽语义拒绝，而非余额不足语义

#### Scenario: 次月自动恢复
- **WHEN** 新自然月开始
- **THEN** 该客户额度自动重置为满额，无人工开闸动作

### Requirement: 档位后台可配不发版

档位数字（月费、含额行数）存于后端计费库，运营经内部端点调整后前台即期生效，不需要前端发版；前台定价页活取公开档位端点，源码不携带档位价格与行数面量。

#### Scenario: 改价不发版
- **WHEN** 运营经内部端点调整某公开档位的含额行数并保存
- **THEN** 前台定价页在无需发版的情况下呈现新数字

#### Scenario: 源码无档位面量
- **WHEN** 检查前端构建产物
- **THEN** 不含档位月费与含额行数的硬编码字面量（目录规模等活取统计数字不受此约束）

### Requirement: 自定义档建档与指派

内部端点支持创建自定义档（询价定案后的月费/含额），创建后不进入公开档位列表；可指派给指定客户，指派后该客户的行数门与结算按自定义档口径生效。

#### Scenario: 询价建档指派
- **WHEN** admin 创建自定义档并指派给客户 C
- **THEN** C 的月度额度按该档含额生效，公开档位端点不返回该档

### Requirement: 旧三档禁用退场

starter/professional/enterprise 三档以禁用（is_active=false）方式退场，行保留可审计；因无存量客户，不存在在途账务迁移；禁用后不可再指派给新客户。

#### Scenario: 旧档不可指派
- **WHEN** admin 尝试将禁用档位指派给客户
- **THEN** 被拒绝；内部档位列表仍可看到旧三档及其禁用标记
