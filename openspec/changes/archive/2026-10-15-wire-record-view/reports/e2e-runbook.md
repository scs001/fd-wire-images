## 场景数据（一次备齐，可与 form-entry-advanced 剧本共用一套）

1. 数据集 `批次`（api 档）：列 `批次号(TEXT)`、`产品名称(TEXT)`、`产地(TEXT)`、
   `负责人(TEXT)`、`联系电话(TEXT)`、`地块编号(TEXT)`；行：`B20261015-A1 /
   苦瓜 / 宜昌基地 / 张三 / 138… / A1`。
2. 数据集 `打药记录`（api 档）：列 `记录日期(DATE)`、`地块编号(TEXT)`、
   `农药名称(TEXT)`；行 2 条（A1 地块，不同日期）。
3. 数据集 `采收记录`（api 档）：列 `记录日期(DATE)`、`地块编号(TEXT)`、
   `产量(TEXT)`。

## 步骤

### 一、构建与预览（console）

1. 产物页「新建 → 单记录页」→ 空白创建（最小 spec），进构建器。
2. 配置：主数据集=批次、键列=批次号；headerFields=[产品名称/产地/负责人/
   联系电话]（label 改写一处验证）；sections=[打药记录（dateColumn=记录日期，
   filters=[{column:地块编号, op:eq, value:{fromField:地块编号}}]）、
   采收记录（同构）]；保存 → 版本递增。
3. **未绑中间态**：新建另一个不配主数据集就保存 → 可保存；点生成分享 →
   被 403 拒（不发扫码即 404 的链接）。
4. 试预览：键值下拉出现 `B20261015-A1`（distinct 查询）；选中 → 预览渲染
   header 区+两段时间轴（升序、节点可展开全列）。

### 二、发布与二维码

5. 发布 → 分享弹层：TTL 档出现 **0=不设期（印刷物）** 且带撤销提示；选 0
   生成 → expires_at 显示「不设期」而非 1970/空串。
6. 选批次号 → 展示完整 URL（`…/#/share/record-view/{id}?t=…&k=…`）→
   下载 PNG（扫码清晰）与 SVG（矢量无损）；二维码图仅在点开弹层后加载
   （网络面板：browser-*.js 懒 chunk，公开页 bundle 无此请求）。

### 三、扫码（手机，无痕/未登录）

7. 扫 PNG → 打开页面：header 四字段 + 打药两节点 + 采收获节点，按日期
   升序；点节点展开该行全部列值。
8. 无此批次：手改 URL k=不存在的值 → 「无此记录」态（非 404 错误页、非
   令牌失效页——三者文案可区分）。
9. 令牌篡改：改 t 一位 → 统一「链接无效」404 态。

### 四、实时性与撤销

10. console 向 `打药记录` 补录一行（行内编辑器 insert）→ ≤60 秒后刷新扫码
    页 → 新节点出现（缓存 TTL 内允许延迟）。
11. 归档该产物 → 再扫码 → 404 失效页（0 档长效令牌同样失效）；恢复
    published 后需重新生成链接。

### 五、顺带回归（存量零漂移）

- dashboard/form 生成分享：缺省仍 30 天；选 0 档同样可选（三类同享）、
  expires_at=null；既有 7/30/90 档链接行为不变。
- 工作台徽标出现「单记录页」计数；AI 生成产物门里**无** record-view。
- 公开取数端点限流：同令牌高频刷新 → 429「请求过于频繁」可读态。
