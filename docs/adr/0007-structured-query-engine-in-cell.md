# 结构化查询引擎置于 cell 引擎侧，暴露结构化查询而非 SQL

客户数据的查询/聚合/派生执行层建在 cell 引擎（DAAS customer-dataset 组）里，MCP 工具与 REST 数据面两个入口共享同一执行层，永不漂移；对外暴露结构化查询语义（过滤/排序/分页/计数/去重/聚合），不暴露裸 SQL。裸 SQL 有注入面、行数与超时纪律难约束、且把存储实现（sqlite）泄漏进对外契约；放在 wire api 侧直查数据库则会形成第二执行层，与引擎工具面漂移。派生（含与平台指标 join）同样在引擎侧物化，血缘留档。

## Considered Options

- wire api 直连 cell 库执行查询（否决：第二执行层，工具面漂移）
- 只读 SQL 子集直通（否决：契约泄漏存储实现，纪律约束弱；留作后续可选项）
